# Convenciones

## Fuentes

Cada snapshot de `raw/` debe indicar origen, versión o fecha, hash SHA-256 y fecha de ingestión en `raw/manifest.md`.

## Conocimiento

Las páginas deben etiquetar cada afirmación durable como `HECHO`, `DECISIÓN`, `PREFERENCIA` o `PREGUNTA ABIERTA`, e incluir la fuente o decisión relacionada.

## Enlaces

Usar enlaces relativos Markdown. Toda página nueva debe aparecer en `wiki/index.md` y tener al menos una referencia entrante, salvo páginas índice.
