# Esquema de la LLM Wiki

Esta carpeta define cómo se organiza y mantiene la wiki global del workspace.

- `convenciones.md`: nombres, estados de conocimiento, enlaces y metadatos.
- `workflow-ingest-query-learn-lint.md`: operaciones permitidas y su evidencia.
- `clasificacion-de-conocimiento.md`: clasificación `HECHO`, `DECISIÓN`, `PREFERENCIA` y `PREGUNTA ABIERTA`.

Las fuentes de `raw/` son inmutables. Las páginas de `wiki/` son síntesis mantenidas por el agente.
